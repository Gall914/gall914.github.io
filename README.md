# RetroMesh

Ретро-мессенджер (PWA) на Firebase. Запускается статикой — GitHub Pages.

```
index.html      только разметка экранов и подключение файлов
manifest.json   PWA-манифест
sw.js           service worker (кеш, уведомления)
icon-*.png      иконки
css/            стили по экранам; theme.css — оформление поверх (грузится последним)
js/             код по модулям; порядок подключения в index.html важен
```

Ключи (EmailJS, Firebase, Groq) лежат в `js/config.js`.
**Ключ Groq виден всем посетителям сайта — его нужно перевыпустить** и по возможности перенести на серверную функцию.
